# Who falls asleep first at Christmas?

A fictional Python project that ranks six family members using a simple sleepiness score.

## Run

Requires Python 3.10 or newer. No additional packages are needed.

```bash
python 02_scripts/01_validate_data.py
python 02_scripts/02_score_guests.py
python 02_scripts/03_create_report.py
```

See `03_outputs/02_prediction.md` for the predicted winner.
